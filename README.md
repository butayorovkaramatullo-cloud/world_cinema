# World Cinema

Film sayti uchun premium dizayn namunasi. Butun sayt bitta `index.html` faylidan iborat, kompyuter ekrani uchun moʻljallangan va qora-neon ranglarda.

## Ishlaydigan qismlar

- Premyera banneri: oʻzi almashadi, strelka va nuqtalar bilan ham boshqariladi
- Janr boʻyicha filtr va qidiruv
- Film oynasi: maʼlumotlar, pleyer namunasi va sifatni tanlash
- Saqlanganlar roʻyxati (brauzerda eslab qolinadi)
- Hafta topi, toʻplamlar, seriallar va Premium bloki

## Ochish

`index.html` faylini brauzerda oching. Yoki GitHub Pages yoqilgan boʻlsa:
`https://butayorovkaramatullo-cloud.github.io/world_cinema/`

## Hali qilinmagan

- Haqiqiy video manbasi, roʻyxatdan oʻtish va toʻlov ulanmagan
- Posterlar, reytinglar va narxlar oʻrnida `[0.0]`, `[NARX]`, `[Poster]` kabi joy belgilari turibdi
- Saytda faqat huquqi yoki litsenziyasi bor filmlarni joylang
